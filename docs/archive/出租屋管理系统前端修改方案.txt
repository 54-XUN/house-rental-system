# 房屋出租管理系统 — 布局微调任务说明书（终稿）

## 一、侧边栏菜单调整

### 1.1 菜单顺序
从上到下依次为：
1. 统计看板
2. 房源列表
3. 房源明细
4. 客户管理
5. 交易流水
6. 参数设置

删除独立的“添加房源”菜单项。

### 1.2 侧边栏样式
- 菜单项文字颜色：**白色** (`#FFFFFF`)
- 菜单项图标颜色：**白色** (`#FFFFFF`)
- 菜单项悬停背景色：**浅蓝色**（例如 `rgba(64, 158, 255, 0.2)` 或 `#E6F0FF`）
- 菜单项选中背景色：**浅蓝色**（与悬停一致或稍深，但仍比原色淡）

## 二、房源列表页面

### 2.1 页面布局
- 去掉页面左上角的“房源列表”标题。
- 顶部右侧水平排列四个按钮（从左到右）：
  1. **添加房源**
  2. **全部折叠 / 全部展开**（同一按钮，文字动态切换）
  3. **全部房源**（触发进度条并自动全部展开）
  4. **高级筛选**（弹出筛选弹窗）

### 2.2 房源显示样式
- 采用**网格卡片**布局。
- 每行显示的卡片数量由参数设置中的“列表卡片列数”控制，**默认值为5**。
- 每个卡片包含：
  - 第一行：详细地址
  - 第二行：户型、面积、租金、“详情”文字（或按钮），水平排列。
- 点击“详情”跳转到“房源明细”页面，并高亮对应房源。

### 2.3 分组与折叠
- 按**小区名称**分组，每个分组标题为小区名称。
- 每个分组标题右侧有单独的展开/收起图标（+/-）。
- **初次加载时，所有小区分组默认全部展开**。
- “全部折叠”按钮：收起所有分组，只显示小区名称，按钮文字变为“全部展开”。
- “全部展开”按钮：展开所有分组，按钮文字变为“全部折叠”。
- “全部房源”按钮：显示进度条（当前进度 X --- Y），完成后弹窗“加载完成”，并自动执行“全部展开”。

### 2.4 添加房源弹窗
- 点击“添加房源”按钮，弹出表单弹窗。
- 字段：房源编号（自动生成或手动）、小区名称（下拉，来自 settings）、详细地址、楼层、室、厅、面积、租金、添加日期（日期选择器）、房源标签（多选框）。
- 弹窗底部有“保存”、“重置”、“返回”按钮。
- 保存后关闭弹窗并刷新房源列表。

## 三、房源明细页面

- 保持侧边栏独立菜单。
- 表格显示**所有列**（与 Excel“房源明细”完全一致）：
  添加日期、房源编号、小区名称、详细地址、楼层、室、厅、面积、租金、房源标签、当前合同编号、到期日、房屋状态、操作（查看|开单）。
- 操作列：“查看”可跳转详情，“开单”跳转添加交易页面并预填房源编号。
- 顶部保留“状态刷新”按钮（可选）。

## 四、客户管理页面

### 4.1 页面布局
- 保留左上角“客户明细”标题。
- 顶部右侧水平排列按钮（从左到右）：
  1. **添加客户**
  2. **全部**
  3. **跟进中**
  4. **已签单**
  5. **已放弃**
- 表格显示所有列：添加日期、客户编号、姓名、身份证号、联系电话、微信、标签、状态。
- 每行末尾添加**编辑**和**删除**按钮。
- 表格样式：表头背景色为**浅蓝色**（接近 Excel），其余保持 Element Plus 默认样式。

### 4.2 添加客户弹窗
- 点击“添加客户”弹出弹窗，字段：客户编号（自动生成）、客户姓名、身份证号、联系电话、微信、标签。
- 标签字段旁有一个**“选”**按钮。
- 点击“选”按钮，弹出第二个弹窗，列出所有可选标签（复选框，来源于 settings 中的 `house_tags`），用户勾选后确认，标签值回填到主表单（以逗号分隔显示）。
- 主表单底部有“确认”、“关闭”按钮。

### 4.3 编辑与删除
- 编辑：弹出与添加相同的弹窗，预填数据，保存后更新。
- 删除：需二次确认。

## 五、交易流水页面

### 5.1 页面布局
- 保留左上角“合同信息”标题。
- 顶部右侧添加**“添加交易”**按钮。
- 表格显示所有列：签订日期、合同编号、租住月数、起始日期、结束日期、押金金额、合同金额、房源编号、每月租金、客户编号、操作。
- 操作列只有**“查看”**按钮。

### 5.2 添加交易弹窗
- 点击“添加交易”弹出弹窗，风格与“添加客户”弹窗一致。
- 弹窗分三部分：
  - **合同信息**：合同编号（自动生成）、租住月数、起始日期、结束日期、押金金额、合同金额（自动计算 = 租住月数 × 每月租金 + 押金，押金为空则为0）。
  - **房源信息**：房源编号输入框（失焦自动带出小区名称、详细地址、楼层、室、厅、面积、租金、房源标签，这些字段只读或自动填充）。
  - **客户信息**：客户编号输入框（失焦自动带出姓名、身份证号、联系电话）。
- 弹窗底部有**“保存”、“重置”、“返回”**按钮。

### 5.3 查看交易弹窗
- 点击“查看”弹出弹窗，内容与添加交易弹窗相同，但**所有字段可编辑**（合同编号不可改）。
- 弹窗底部有四个按钮（从左到右）：
  1. **保存**（更新合同，刷新表格，关闭弹窗）
  2. **重置**（恢复未保存的修改）
  3. **返回**（关闭弹窗）
  4. **删除**（红色背景，点击后二次确认，确认后删除合同并刷新表格，关闭弹窗）

## 六、统计看板页面

### 6.1 整体布局（五部分）

#### 第一部分：数据概览（白框）
- 白框左上角标题：“数据概览”
- 白框右上角两个图标：**刷新图标**（重新加载所有看板数据）和**详情图标**（打开看板数据抽屉）
- 内部四个指标卡片（水平排列）：
  - 当前房源数量
  - 本月成交金额
  - 本月成交数量
  - 客户数量
- 数据来源：
  - 当前房源数量：`houses` 表总数
  - 本月成交金额：`contracts` 表中 `sign_date` 为本月的 `total_amount` 总和
  - 本月成交数量：`contracts` 表中 `sign_date` 为本月的合同数量
  - 客户数量：`customers` 表总数

#### 第二部分：成交金额
- 标题：“成交金额”
- 折线图：横轴为最近15天（格式 `MM/DD`），纵轴为每日成交金额总和（按 `sign_date` 分组）。
- 折线图下方显示一行文字：“X月X日成交金额最高 Y元”（取15天内的最大值及其日期）。

#### 第三部分：房源分布
- 标题：“房源分布”
- 饼图或圆环图，显示“空闲”、“已租”、“即将到期”三种状态的数量及占比。
- 图例或图表旁显示出租率 = `已租数量 / 房源总数 * 100%`。
- 可选：显示三个状态的具体数值（如“空闲数量：68”）。

#### 第四部分：新增客户与小区排名（左右两列布局）

**左侧：新增客户**
- 标题：“新增客户”
- 柱状图：横轴为最近7个月（格式 `YYYY年MM月`，从当前月往前推7个月），纵轴为每月新增客户数量（按 `add_date` 统计）。
- 柱状图下方显示一行文字：“X月新增客户最高 Y人”。

**右侧：小区排名**
- 标题：“小区排名”
- 显示一行摘要：“小区名称A房源最多 15套”（取房源数量最高的小区及数量）。
- 下方表格：排名前5的小区及对应房源数量（两列：小区名称、房源数量）。

#### 第五部分：看板数据抽屉
- 点击“数据概览”白框右上角的**详情图标**，从右侧滑出一个**抽屉**（Drawer，宽度约80%）。
- 抽屉标题：“看板数据”。
- 抽屉内以多个**只读表格**展示以下数据（来源于已有的看板API）：
  1. 房源分布统计（字段：状态、数量）
  2. 成交金额明细（最近15天：日期、金额）
  3. 新增客户明细（最近7个月：年月、新增人数）
  4. 小区排名（前5名：小区名称、房源数量）
  5. 最高成交日（日期、金额）
  6. 最高新增客户月（月份、人数）
- 抽屉底部有关闭按钮。
- 打开抽屉时，自动刷新数据（调用同一套看板API）。

### 6.2 其他
- 所有图表在无数据时显示“暂无数据”或占位提示。
- 刷新图标点击后重新调用所有看板API并刷新页面内容。

## 七、参数设置页面

### 7.1 整体布局（三列）
- **左侧**：列表卡片设置
  - 列表卡片列数（数字输入，默认5，范围1-10）
  - 房源空闲样式：固定绿色色块（不可修改，不显示文字）
  - 房源已租样式：固定灰色色块
  - 房源即将到期样式：固定橙色色块
  - 即将到期提醒天数（数字输入，默认30）

- **中间**：字段设置，分为左右两列
  - 左列：小区名称列表（只读展示，显示小区名称A ~ 小区名称I，共9行，仅作演示，不可增删改）
  - 右列：房源标签列表（只读展示，显示楼层低、有电梯、近地铁、有家具、有空调、有车位、精装修、民水民电、随时看房，共9行，仅作演示，不可增删改）

- **右侧**：模板初始化
  - 按钮：“模板初始化”
  - 按钮下方显示说明文字：“注：初始化功能会将【房源明细】、【客户管理】、【交易流水】这三个工作中的数据清空，同时列表卡片恢复默认设置，操作前请数据备份！”
  - 点击按钮需二次确认，确认后调用 `POST /api/settings/reset`。

### 7.2 其他
- 页面顶部不显示“参数设置”标题。
- 保持 Element Plus 默认样式，但数字输入框使用 `el-input-number`。

## 八、技术实现要点

- 所有弹窗支持键盘 ESC 关闭，点击遮罩可关闭。
- 日期选择器使用 `el-date-picker`。
- 标签选择二级弹窗：读取 `/api/settings` 中的 `house_tags` 数组，渲染复选框列表。
- 网格卡片布局：CSS Grid，`grid-template-columns: repeat(card_columns, 1fr)`，`card_columns` 从 `/api/settings` 读取（默认5）。
- 全部房源进度条：模拟进度（快速闪过），不执行真实长时间加载。
- 看板图表使用 ECharts，数据通过 `/api/dashboard/...` 接口获取。
- 看板刷新图标：调用 `fetchDashboardData()` 重新获取所有看板数据。
- 看板详情图标：打开抽屉，抽屉内表格直接使用已获取的看板数据（不需额外接口）。
